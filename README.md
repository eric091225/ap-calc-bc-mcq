# AP Calculus BC · MCQ 题库

单文件网页版 AP 微积分 BC 选择题练习题库，对应 **2025–2026 考纲**，覆盖 CED 考点 111/111，共 **933 题**。纯前端、零依赖、可完全离线使用。

- **在线练习**：https://eric091225.github.io/ap-calc-bc-mcq/
- **离线使用**：下载 `index.html`，双击用浏览器打开即可，不需要联网、不需要安装任何东西。

## 关于本项目

做这个题库的初衷很简单：**让 AP 微积分 BC 的学习者能真正掌握知识，而不是靠刷题背答案。**

市面上的练习资源要么零散、要么把答案和题目分开，学习者做完一遍往往不知道自己错在哪个知识点上。所以这个题库把三件事绑在了一起——题目、逐题解析、以及**错因标注**（比如「FTC 方向错误」「链式法则遗漏」「计算器模式错误」）。目标是让每做错一道题，都能定位到具体是哪个概念没通，而不是只知道选错了一个字母。

- **纯公益性质。** 完全免费，无广告、无付费墙、不收集任何用户数据、不做任何商业变现。做出来就是给需要的人用的。

## 功能

- **单元筛选**：U1–U10 按单元刷题，也可按题目表征筛选
- **进度记录**：进入时输入一个用户名，答题进度自动保存；同一浏览器下次打开自动接续
- **数据统计**：实时显示已答 / 答对 / 答错 / **首答正确率**，并按单元分别统计进度
- **逐题解析**：每题附解析，并标注易错点（如「FTC 方向错误」「链式法则遗漏」「计算器模式错误」）
- **公式排版**：数学公式用 KaTeX 渲染，可一键切换「公式排版」开关
- **考点索引**：按 CED 考点快速定位题目

## 使用约定

> 本节是使用本题库的几条要求，请先读完再开始刷题。

1. **先独立做，再看解析。** 每道题至少认真想满 2 分钟再展开解析；直接看答案对提分没有意义——统计里的「首答正确率」才是真实水平，看完解析再选的正确率是假的。
2. **不要重置进度来刷好看的正确率。** 「重置」只在换人使用时才用。错题记录是这个题库最有价值的部分。
3. **错题必须二刷。** 每完成一个单元，回到该单元把答错的题重做一遍，直到能说清楚错在哪一步，而不只是记住正确选项是哪个字母。
4. **注意 Part A / Part B 标签。** Part A 是**不允许用计算器**的部分，做这类题时请把计算器收起来；Part B 才可以用。
5. **计算器统一用弧度模式（RAD）。** 题库里有专门针对「角度/弧度模式错误」的陷阱题，考试中这也是高频失分点。
6. **按单元推进，不要跳着做。** U1–U10 是有依赖关系的，前面的单元没过关，后面单元的错误往往只是前面漏洞的表现。

## 遇到问题怎么办

**先做这三步自查**，绝大多数问题都能解决：

1. **强制刷新页面**：`Cmd + Shift + R`（Mac）/ `Ctrl + F5`（Windows）。公式没渲染出来、页面显示错乱，多半是缓存问题，刷新即可。
2. **换用现代浏览器**：推荐 Chrome、Edge、Safari 的最新版本。IE 和过旧版本浏览器不支持本页面用到的特性。
3. **确认没开无痕/隐私模式**：无痕模式下浏览器会限制本地存储，导致**进度无法保存**。

### 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 公式显示成一堆乱码或源码 | 点顶部「公式排版」开关切换一次；仍不行则强制刷新页面 |
| 进度丢了 / 重新要求输入用户名 | 进度存在**本机浏览器**里，清理浏览器数据、换浏览器、换设备、无痕模式都会导致进度不同步。这是设计如此，不是故障 |
| 换了台电脑，进度没跟过来 | 同上，进度不上云。需要跨设备请手动用「导出」功能 |
| 页面打开很慢 | 单文件约 4 MB，首次加载稍慢属正常；之后浏览器会缓存 |
| 手机上排版拥挤 | 建议横屏，或改用平板/电脑练习。图像题在小屏上确实不好看 |
| 图形（Graph / Slope field）不显示 | 图形是内联 SVG，理论上不会加载失败。如出现，请强制刷新并反馈 |

### 发现题目本身有错怎么办

如果你认为某道题的**答案或解析有误**，请**先自己复核一遍**——很多时候是自己的理解偏差。确认确实有问题后，按以下格式反馈：

在 [Issues](https://github.com/eric091225/ap-calc-bc-mcq/issues) 里新建一条，写清楚：

- 题号（页面上的 `Q01` 这类编号）和所属单元
- 你认为正确的答案是哪个选项
- **你的推导过程**（这一条最重要，只说「答案错了」无法处理）

### 其他问题

上面都没覆盖到的，同样提 [Issue](https://github.com/eric091225/ap-calc-bc-mcq/issues)，请附上：浏览器及版本、操作系统、问题截图、以及复现步骤（做了什么操作导致的）。

## 技术说明

- 单个 `index.html`，约 4 MB，**无任何外部网络请求**——KaTeX 样式、字体回退、全部图形（内联 SVG）都打包在文件内
- 进度通过浏览器 `localStorage` 保存，键名为 `apcalc_session_user`、`apcalc_recent`、`apbc_math`、`apbc_dense`
- 数据只存在本地浏览器中，不上传、不经过任何服务器
